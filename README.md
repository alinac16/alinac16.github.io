## About

A single-page portfolio built from scratch with vanilla HTML, CSS, and JavaScript. Designed with a dark earth-toned aesthetic inspired by 1Password's brand.

## Sections

- **About** — Intro, bio, and contact links
- **Work** — Experience timeline, technical skills, education, and projects
- **Passion** — Life outside work, featuring a live Instagram feed via [Behold](https://behold.so)

## Features

- Alternating scroll-animated experience timeline
- Cursor glow effect that follows the mouse
- Instagram feed embedded via Behold widget
- Fully responsive across desktop and mobile
- Company logos and cartoon avatar

## Tech Stack

- HTML / CSS / JavaScript (no frameworks)
- Google Fonts — Inter
- [Behold](https://behold.so) for Instagram feed
- Hosted on GitHub Pages
